# DrawLab

Este projeto, chamado **DrawLab**, é um **projeto pessoal e fictício** desenvolvido para consolidar minhas habilidades de **desenvolvimento front-end** com **Angular** e **Sass**.

O objetivo foi criar a **página inicial responsiva de uma empresa de cursos de design digital**, com um foco forte na **User Interface (UI)** e na implementação do código.

> **Importante:** Este projeto priorizou o **design de interface (UI)** e o **desenvolvimento**, mas **não** incluiu a etapa de **pesquisa de User Experience (UX)**.

## Tecnologias e Decisões Técnicas

  * **Angular:** Utilizado para a arquitetura de componentes e a criação de uma interface dinâmica.
  * **Sass:** Implementado para agilizar e facilitar o desenvolvimento de estilos. Foram criadas **variáveis globais** e **mixins reutilizáveis** para manter a consistência, simplificar a manutenção do código e reforçar o conceito de *design system*.

## Como executar localmente

### Pré-requisitos

Antes de começar, você precisa ter instalado na sua máquina:

  * [Node.js](https://nodejs.org/)
  * [Angular CLI](https://angular.io/cli)
  * [Git](https://git-scm.com/)

### Passo a passo

1.  **Clone o repositório**

    ```bash
    git clone https://github.com/Thyale/DrawLab.git
    ```

2.  **Acesse a pasta do projeto**

    ```bash
    cd drawlabmain
    ```

3.  **Instale as dependências**

    ```bash
    npm install
    ```

4.  **Execute o projeto**

    ```bash
    ng serve
    ```

5.  **Abra no navegador**

    ```
    http://localhost:4200/
    ```
